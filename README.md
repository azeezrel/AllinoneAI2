# AllinOne AI Agent
 
## Overview
 
The AllinOne AI Agent is an AI-powered SRE assistant designed to monitor, analyse, and troubleshoot Azure resources.
 
## Key Capabilities
 
- Collects Azure metrics, logs, activity data, and resource information.
- Analyses operational data to identify potential root causes.
- Uses OpenAI/Azure OpenAI for AI-powered incident analysis.
- Generates actionable troubleshooting and remediation steps.
- Provides ready-to-use Azure CLI, PowerShell, and Kubernetes commands.
- Automatically analyses alerts and incidents.
- Automatically sends root cause analysis and recommendations to Microsoft Teams.
 
## Outcome
 
The AI Agent helps reduce manual troubleshooting effort and MTTR by turning Azure operational data into actionable insights and automated incident notifications.
